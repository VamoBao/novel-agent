# 顶栏小说切换器设计

2026-11-13，用户确认「切换小说移到左上角下拉（类 Android Studio 项目切换），纯切换；管理放切换器旁的独立按钮；彻底移除左侧书库栏；小说名替换顶栏应用名」。遵循 DESIGN.md 与既有书库工作区令牌。

## 布局

- 顶栏左侧：`NovelSwitcher`（书本图标 + 当前小说名 + ▾）+ 相邻「书库管理」图标按钮；替换原汉堡折叠、`novel-agent` 标题与「创作书库」文案。OS 标题栏仍显示应用名。
- 工作区由三栏改为两栏（结构树 + 预览），移除 sidebar 与折叠态；700px 以下原「书库转顶部横条」断点退役，两栏在窄窗继续分栏。
- 顶栏右侧（设置 + 新建小说）不变。

## 切换器（纯切换）

按钮常显当前小说名（无选中显示「选择小说」，加载中显示占位并禁用）。下拉为小说列表，沿用现有排序（置顶优先），当前项高亮 + 勾选标记；置顶/收藏为只读小图标，不承载操作。点击条目切换并收起；Esc / 点击面板外关闭；↑↓ 键盘导航 + Enter 选择，焦点回按钮。空态提示新建入口在右上；加载与错误态在面板内呈现（错误附重试）。无右键、无管理操作。

## 书库管理弹层

管理按钮打开弹层，承载原 `NovelListPanel` 全部职责：列表行 + 右键菜单（重命名 / 置顶 / 收藏 / 写作偏好 / 删除）、行内重命名、刷新、计数。行尾悬停显示「⋯」按钮唤出同一菜单（右键照旧），点击行切换选中并收起弹层。删除仍走 `DeleteNovelDialog` 强确认、写作偏好仍走 App 级 `WritingPrefsDialog`，IPC 契约零变化。切换下拉与管理弹层互斥：打开一个关闭另一个。

## 边界

- 不改数据层 / IPC / 协议 / 结构树 / 预览内容；不做下拉搜索；「新建小说」保持在右上。
- 详情加载、生成中会话的中止行为随选中变化照旧（PreviewPane 卸载即 agent:stop）。
- 诊断钩子（AUTOSTART / SELECT / SCREENSHOT / THEME）不受影响。

## 验收

真 React+IPC 交互测试覆盖：切换器选择联动、当前项标识、管理弹层五项操作全流程（重命名 / 置顶 / 收藏 / 写作偏好 / 删除强确认）、弹层互斥、键盘（Esc / ↑↓）与空 / 错误态；更新既有三个引用 `.novel-item` 的测试。全量 typecheck / lint / test 通过；Electron 浅暗 × 宽窄窗口截图目测无溢出错乱。
