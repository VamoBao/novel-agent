# 章节正文重新生成 设计规格

> 状态：**已确认**（2026-10-12——两项决策经用户确认：①旧正文覆盖替换（归档历史版本为后续独立需求）；②客户端弹框确认（对齐 OutlineRegenDialog 先例）。设计经用户确认后开始执行。）
> 需求来源：用户提出——已生成正文的章支持「重新生成」，添加一个重新生成按钮，流程和新生成正文一个流程（即完整的三段校验-修订闭环）。
> 前置依赖：校验-修订闭环已落地（write-chapter 3 轮循环 + chapter-review + write-progress 进度展示）；documents 一章一份（chapter_id 唯一索引）；「已有正文」拒绝存在于两层（write-chapter 前置校验 + document-store.saveChapterDocument）。

## 1. 背景与问题

当前一章只能生成一次正文（`已有正文，重新生成为后续需求` 双层拒绝）：用户对正文不满意时（或手改搞坏后）没有任何再生成手段，只能手工删库删文件。本需求开放「重新生成」——同一 write-chapter 会话、同一校验-修订流程，覆盖替换旧正文。

## 2. 用户确认的决策

1. **旧正文覆盖替换**：新正文通过校验后，删旧 documents 行插新行（同事务）、删旧正文文件；无归档。失败（校验抛错 / 中止 / 库故障）时旧正文零影响。归档历史版本（类似 character_versions / 大纲多版本先例）为后续独立需求。
2. **弹框确认**：对齐 OutlineRegenDialog 先例——模态警示「将覆盖现有正文（不可恢复），重新生成会走完整的三段校验-修订流程」，确认后才发起会话。

## 3. 详细设计

### 3.1 流程（与新生成完全一致，协议层零改动）

同一 `write-chapter <novelId> <chapterNodeId>` 会话、同一 write-progress 进度消息。差异仅三点：

1. **前置校验**：移除「已有正文」拒绝——`getDocumentByChapter` 有行即走重生成路径（`isRegen`），无行走既有新生成路径；
2. **notify**：启动文案区分——重生成「🔄 重新生成中（《书名》· 章名，写作模型，将覆盖现有正文）…」；
3. **保存段**：`save-or-replace`——
   - 新文件先写（`buildChapterDocumentPath` 的 `-N` 后缀逻辑天然不覆盖旧文件：旧 `章名.md` 在则新落 `章名-2.md`；旧 `-2` 在则新落回 `章名.md`——路径在两三个名字间交替，不无限增长）；
   - 库操作按路径分流：无旧行 → 既有 `saveChapterDocument`；有旧行 → 新增 `documentStore.replaceChapterDocument`（单事务「删旧 documents 行 → 插新行 → 回写章节点 document_id + status=completed」，校验同 save：章节点存在 / 同小说 / 类型 chapter / filePath 非空；无旧行时行为等同首次保存）；
   - 事务提交成功后删旧正文文件（`existing.filePath !== 新路径` 时；文件缺失容忍不阻塞——行已指向新文件，孤儿旧文件无害）；任一环节失败：回滚删新文件、抛错，旧正文行与文件零影响。

### 3.2 客户端

- **OutlineNodeCard**：有正文的章卡新增「🔄 重新生成」入口（与「✍️ 生成本章正文」互斥显示——有正文显示重生成、无正文显示生成；生成中一并禁用）；置于卡片动作区右对齐（对齐既有 act-actions 布局）。
- **ChapterRegenDialog（新组件）**：模态警示弹框（镜像 OutlineRegenDialog 结构）——章名、覆盖警告（不可恢复）、流程说明（完整三段校验-修订循环，有真实 LLM 成本）；确认 / 取消。
- **PreviewPane**：持有「待确认重生成的章节点」状态；弹框确认后复用既有 `startWriteChapter`（同一会话启动）；生成态、进度区块（与正文卡并存展示）、run_finished 刷新、卸载中止——全部复用现有内联会话收口，零新增订阅逻辑。

## 4. 错误处理

- 保存事务失败 / 校验抛错 / 会话中止：新文件回滚删除，旧 documents 行与旧文件原样保留（用户可重试或放弃）；
- 旧文件清理失败（已被手工移走等）：容忍不阻塞——行已指向新文件，孤儿旧文件无害，不告警。

## 5. 测试计划

- document-store 单测：替换生效（行数 1、新 filePath/wordCount、章节点 documentId 更新）/ 无旧行等同首次保存 / 非章节点与异小说拒绝；
- write-chapter 集成：重生成成功（新内容入库、旧行旧文件清理、notify 🔄）/ 库故障回滚（旧正文行与文件完好、新文件无残留）/ 校验抛错保旧；
- 既有回归：新生成全部用例不变；前置校验用例中「已有正文拒绝」移除（行为翻转）；
- 客户端 SSR 冒烟：有正文章卡显示重生成入口 / 生成中禁用 / 弹框渲染。

## 6. 不做范围

- 旧正文归档 / 历史版本浏览回切（覆盖即失，后续独立需求）；
- 正文手改后重新生成时的 diff 预览；
- 协议与 headless 零改动（复用同一会话模式与进度消息）。
